## Публічний зразок для клієнтів

- **Сайт:** https://pavza-web-production.up.railway.app/
- **Демонстрація адмінпанелі (вхід захищений):** https://pavza-web-production.up.railway.app/admin.html
- **Статус:** Railway повідомив `SUCCESS` та `Online` 17 листопада 2026 року. Зовнішній браузерний тест ще потрібен.
- **Тип:** портфоліо-концепт VERES DESIGN, **не реальна кав’ярня**. Публічні бронювання та надсилання відгуків вимкнені (`PAVZA_ALLOW_SUBMISSIONS=0`).
- **Розгортання:** тимчасово використано публічний образ `python:3.12-slim` із завантаженням закріпленої ревізії коду з цього GitHub-репозиторію під час старту. **Нові коміти GitHub не публікуються автоматично.** Для регулярних оновлень під'єднайте GitHub безпосередньо у Railway та поверніться до Dockerfile-розгортання.
- **Увага:** працюючий сервіс та volume можуть використовувати кредити Railway або призводити до списань залежно від тарифу.

## Функціональність

- Узгоджений єдиний інтер’єр PAVZA, адаптивний сайт, фотографії, меню-карусель, коротка локальна відеоанімація.
- FastAPI + SQLite: менеджмент меню, попередні заявки, перевірка конфліктів столиків, відгуки з модерацією, CSV заявок, агрегована статистика зі згодою.
- Адміністратор: парольно захищена сесія з HttpOnly cookie і CSRF токеном, зміна пароля з відкликанням інших сесій, видалення персональних даних і відгуків.
- Приватна база та секрети поза `public/` і поза ZIP. Програмні тести є у папці `tests/`.
- **За замовчуванням публічні форми вимкнені:** `PAVZA_ALLOW_SUBMISSIONS=0`. Відвідувач не може надіслати телефон чи відгук до реального підключення. Для локальних інтеграційних тестів: `PAVZA_ALLOW_SUBMISSIONS=1`.
- `noindex` збережено, оскільки заклад вигаданий. При публічному портфоліо показуйте позначку «концепт».
- GA4 і Meta Pixel **не підключені**: потрібні права власника, реальна політика приватності та налаштована згода.

## Онлайн-публікація на Railway

1. Створіть приватний GitHub репозиторій із файлами цієї папки (не завантажуйте `.pavza-data`, паролі, базу чи `.env`).
2. У Railway оберіть **New Project → Deploy from GitHub repo** → цей репозиторій. Dockerfile збере один сервіс із FastAPI і сайтом.
3. Додайте **постійний Volume** із mount path `/data` ДО використання сайту — SQLite та адміндані повинні зберігатися після повторних розгортань.
4. У Railway Variables встановіть `PAVZA_DATA_DIR=/data`, `PAVZA_ALLOW_SUBMISSIONS=0`, `PAVZA_SITE_ENV=portfolio_demo`, `PAVZA_TIMEZONE=Europe/Kyiv`, `PAVZA_ADMIN_PASSWORD` (довільний унікальний пароль не коротший 12 символів; лише при першому створенні БД). Не комітьте секрет у GitHub.
5. У Settings → Networking натисніть **Generate Domain**. Перевірте `/api/health`, `/admin.html`, `/api/config`; при звичайному вході `/api/config` має містити `allowSubmissions:false`.
6. Адмінпанель — за адресою `/admin.html` того самого домену. Змініть початковий пароль у ній; попередні сесії стануть недійсними.
7. Для бекапів запускайте `python backup_db.py` на сервері та переносіть файли на незалежне захищене сховище. Один volume не замінює окремі резервні копії.

**Важливо:** деплой не створено автоматично цим ZIP. Потрібне підключення Railway/GitHub або доступ до панелі хостингу. Статичний Netlify не запускає Python/SQLite сервер. Плани з Volume можуть бути платними — перевіряйте тариф на момент розгортання.

## Локальний запуск Windows

1. Встановіть Python 3.11+.
2. Розпакуйте архів. Двічі натисніть `START_WINDOWS.bat`.
3. Відкрийте `http://127.0.0.1:8000/` і `http://127.0.0.1:8000/admin.html`.
4. Після першого запуску пароль адміністратора зберігається приватно в `.pavza-data/initial-admin-password.txt` (не передавайте нікому).
5. Для тесту форм запустіть із PowerShell: `$env:PAVZA_ALLOW_SUBMISSIONS='1'; python -m uvicorn server:app --host 127.0.0.1 --port 8000`.

## Вміст

- `server.py` — API та SQLite логіка.
- `Dockerfile`, `railway.json`, `.dockerignore` — конфігурація розгортання.
